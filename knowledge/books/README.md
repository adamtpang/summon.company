# Books — distilled frameworks

Book-level knowledge for Summon's agents, following summon.guide's BOOKS.md
method: the PDF stays OUT of git (copyrighted; keep sources on disk or in a
gitignored `_sources/`), the distillation goes in. Each file is frameworks in
our own words, structured like the episode files: frontmatter, one principle
under 140 chars, then the frameworks an agent can actually apply.

Current shelf:
- `100m-offers.md` — Alex Hormozi, offer construction and pricing.
- `100m-leads.md` — Alex Hormozi, the advertising and lead machine.
- `how-to-make-a-few-billion-dollars.md` — Brad Jacobs, trends, rollups, and electric meetings.

Adding a book: distill 3 to 7 frameworks the author actually used, cite the
chapter or section names, keep every claim traceable to the text, no long
quotes. Wire the highest-leverage frameworks into the diagnosis engine
(`apps/landing/api/_precedents.mjs`) and the department playbooks.
